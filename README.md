## 1. Library Selection & README Summary

For this assignment, I chose **React-Bootstrap** as the official React UI component library.

It was installed into the Vite project using:
```bash
npm install react-bootstrap bootstrap
```

Using React-Bootstrap saved substantial time and manual boilerplate by providing ready-to-use accessible components like `Navbar`, `Container`, `Card`, and `Button` with built-in responsive collapsing navigation (`Navbar.Toggle`) and flexbox grid alignments (`Row`, `Col`), eliminating the need to write complex media queries and custom collapse states from scratch.
